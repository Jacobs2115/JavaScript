1. W jaki sposób można określić właściwość danego obiektu?

Sposób 1 – za pomocą kropki:

auto.marka = "Opel Omega";

auto.rok = 1996;

Sposób 2 – za pomocą nawiasów kwadratowych:

auto["cena"] = 25000;

2. W jaki sposób można odwołać się do pól i metod?

Do właściwości i metod odwołujemy się, podając nazwę obiektu, kropkę i nazwę właściwości lub metody.

Przykład: samochod1.kolor

Przykład: samochod1.wypisz()

3. Wymień cechy charakterystyczne konstruktora.

1. Jest uruchamiany automatycznie podczas tworzenia obiektu.

2. Nazywa się tak samo jak klasa.

3. Nie zwraca żadnej wartości.

4. Może przyjmować argumenty, tak jak zwykła funkcja lub metoda.

4. Konstruowanie obiektu – trzy pola i jedna metoda

var osoba_1 =
{
nazwisko: "Kowalski",
imie: "Jan",
zawod: "piekarz",
wyswietl: function ()
{
document.write(this.nazwisko + " " + this.imie);
}
}
osoba_1.wyswietl();

5. Znaczenie słowa this. Jak oddzielamy pola oraz metody?

Słowo kluczowe this pozwala odwołać się do pola lub metody obiektu z wnętrza tego obiektu. Pola i metody w obrębie jednego obiektu oddzielamy przecinkami.

6. Konstruktor w JavaScript – przykład i opis

W JavaScript funkcja może pełnić rolę konstruktora. Konstruktor tworzy obiekt i przypisuje wartości jego właściwościom.

function klient(nazwisko_k, imie_k, zawod_k)
{
this.nazwisko = nazwisko_k;
this.imie = imie_k;
this.zawod = zawod_k;
}

7. Znaczenie słowa kluczowego new

Słowo kluczowe new służy do utworzenia nowego obiektu na podstawie konstruktora.

var osoba1 = new klient("Kowalski", "Jan", "kierowca");

8. Znaczenie słowa kluczowego prototype

Właściwość prototype służy do dodawania metod i właściwości do konstruktora. Dzięki temu każdy nowo utworzony obiekt na podstawie tego konstruktora będzie posiadał dodane właściwości i metody.

function klient()
{
this.nazwisko = "Bielski";
this.imie = "Paweł";
}

klient.prototype.zawod = "kierowca";

klient.prototype.pisz_dane = function ()
{
document.write(this.nazwisko + " " + this.imie);
};

var osoba1 = new klient();
osoba1.pisz_dane();
